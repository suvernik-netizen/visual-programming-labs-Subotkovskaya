# Отчёт по лабораторной работе №3 — Bubble

## Краткое описание

В ходе лабораторной работы №3 было создано веб-приложение на no-code платформе **Bubble** на тему **«Список книг»**. Приложение предназначено для публичного просмотра каталога и работы с книгами: добавления, поиска по названию, редактирования и удаления.

Первоначальный каркас страницы `index` был создан с помощью AI-агента Bubble. Затем интерфейс дорабатывался вручную, изучались Build Guides, создавались и заполнялись типы данных. На отдельной странице `reviews` с помощью AI-агента создан интерфейс отзывов и настроены workflows для полного CRUD (Create, Read, Update, Delete). Все четыре операции с отзывами проверены в Preview.

## Часть 4. Data и Workflows

### 4.1. Data: новая сущность `BookReview`

Для проектирования структуры новой сущности использовался ChatGPT. Промпт:

```text
Я создаю приложение «Список книг» в Bubble. В приложении уже есть сущность Book, которая хранит информацию о книгах.

Предложи новую сущность для хранения отзывов о книгах. Укажи её название на английском языке и минимум 3 поля разных типов данных Bubble (text, number, date, yes/no и другие).

Сущность должна подходить для реализации CRUD: создания, просмотра, редактирования и удаления отзывов.
```

Затем вручную в **Data → Data types** создана сущность **`BookReview`** со следующими полями:

| Поле | Тип данных | Назначение |
|---|---|---|
| `Book` | `Book` | Связь отзыва с существующей книгой |
| `ReviewText` | `text` | Текст отзыва |
| `Rating` | `number` | Оценка книги |
| `ReviewDate` | `date` | Дата отзыва |
| `IsRecommended` | `yes/no` | Признак рекомендации книги |

[Открыть скриншот: структура BookReview](../screenshots/06-data-type.png)

В **Data → App data → All BookReviews** вручную добавлены три записи: отзывы на **«Мастера и Маргариту»**, **«Маленького принца»** и **«Гордость и предубеждение»**. Каждая запись связана с существующей книгой через поле `Book`.

[Открыть скриншот: записи BookReview](../screenshots/07-data-records.png)

### 4.2. Workflows: полный CRUD для `BookReview`

Вручную создана отдельная страница **`reviews`**, после чего в AI-агент Bubble отправлен следующий промпт для генерации интерфейса:

```text
Создай на текущей странице reviews интерфейс для управления отзывами о книгах на русском языке.

Приложение называется «Список книг». Страница должна называться «Отзывы о книгах» и иметь аккуратный современный дизайн в светло-бежевых и тёмно-зелёных цветах, как основная страница приложения.

В базе данных уже существует сущность BookReview со следующими полями:
- Book (тип Book) — книга, к которой относится отзыв.
- ReviewText (text) — текст отзыва.
- Rating (number) — оценка от 1 до 5.
- ReviewDate (date) — дата отзыва.
- IsRecommended (yes/no) — рекомендация книги.

Существующая сущность Book содержит поле title с названием книги.

Создай интерфейс для полного CRUD:

1. Create — форму добавления нового отзыва с выбором существующей книги, оценкой, текстом, датой и рекомендацией.
2. Read — список всех отзывов с названием книги, оценкой, текстом и датой.
3. Update — кнопку «Редактировать» у каждого отзыва с возможностью изменения данных.
4. Delete — кнопку «Удалить» у каждого отзыва с подтверждением удаления.

Используй Repeating Group для отображения отзывов и Popup для редактирования.

Свяжи элементы с существующей сущностью BookReview. Не создавай дублирующие Data Types.

По возможности создай отдельные workflows для Create, Read, Update и Delete. Если какие-либо workflows нельзя создать автоматически, подготовь соответствующие элементы интерфейса для ручной настройки.

Добавь кнопку «Вернуться к списку книг», ведущую на страницу index.
```

После получения первого плана AI был отправлен уточняющий запрос:

```text
Оставь все 15 шагов плана, но измени privacy rule Everyone: разреши публичное чтение BookReview, не предоставляя всем пользователям неограниченный доступ на изменение и удаление. Также предусмотрим отдельный workflow Read для обновления списка отзывов.
```

AI создал страницу отзывов с формой, списком, окнами редактирования и удаления, а также workflows.

### Проверка CRUD в Preview

- **Create:** через форму добавлен тестовый отзыв на «Маленького принца» с оценкой 4/5. Отзыв появился в списке.
- **Read:** в списке отображались три ранее созданных отзыва, включая название книги, оценку, дату и текст.
- **Update:** тестовый отзыв отредактирован; изменение оценки с 4 до 5 и текста успешно отобразилось на странице.
- **Delete:** тестовый отзыв удалён через подтверждение; первоначальные отзывы остались в списке.

[Открыть скриншот: проверка Create в Preview](../screenshots/08-preview-new-review.png)

### Workflow → Create

Событие **Create Button is clicked**, при соблюдении условий заполнения и оценки от 1 до 5. Действия:

1. **Create a new BookReview** — создать отзыв.
2. **Reset relevant inputs** — очистить форму.
3. **Trigger Read reviews (refresh list)** — обновить список.

[Открыть скриншот: workflow Create](../screenshots/09-workflow-create.png)

### Workflow → Read

Отдельный **Custom Event: Read reviews (refresh list)** выполняет **Display list in Reviews List** — обновляет отображаемый Repeating Group.

[Открыть скриншот: workflow Read](../screenshots/11-workflow-read.png)

### Workflow → Update

Событие **Edit Save Button is clicked**, при соблюдении условий заполнения и оценки от 1 до 5. Действия:

1. **Make changes to BookReview** — изменить выбранный отзыв.
2. **Hide Edit Popup** — закрыть окно редактирования.
3. **Reset relevant inputs** — сбросить поля формы.
4. **Trigger Read reviews (refresh list)** — обновить список.

[Открыть скриншот: workflow Update](../screenshots/12-workflow-update.png)

### Workflow → Delete

Событие **Del Confirm Button is clicked**. Действия:

1. **Delete BookReview** — удалить выбранный отзыв.
2. **Hide Del Popup** — закрыть окно подтверждения.
3. **Trigger Read reviews (refresh list)** — обновить список.

[Открыть скриншот: workflow Delete](../screenshots/10-workflow-delete.png)

## Освоенные элементы и workflows

### Элементы UI

- **Header / Body / Footer** — организация страницы.
- **Input / Multiline Input / Date Input** — ввод данных книги и отзыва.
- **Button** — создание, редактирование, удаление и навигация.
- **Text** — заголовки, подписи, счётчик результатов.
- **Repeating Group** — отображение каталога книг и списка отзывов.
- **Popup** — редактирование и подтверждение удаления отзыва.
- **Dropdown** — выбор существующей книги при создании и редактировании отзыва.
- **Checkbox** — признак рекомендации книги.
- **Group** — компоновка элементов.
- **Page** — отдельная страница `reviews`.

### Workflows

- **Create a new thing (`BookReview`)** — создание отзыва.
- **Display list** — отображение/обновление списка в Repeating Group через отдельный Read workflow.
- **Make changes to a thing** — изменение записи.
- **Delete a thing** — удаление записи.
- **Show / Hide Popup** — работа с окнами.
- **Reset relevant inputs** — очистка полей.
- **Trigger a custom event** — запуск обновления списка после изменения данных.
- **Go to page** — переход на страницу `index`.

### Data

- **`Book`:** поля `title` (text), `author` (text), `description` (text), `year` (number).
- **`BookReview`:** поля `Book`, `ReviewText`, `Rating`, `ReviewDate`, `IsRecommended`.
- **App data:** три вручную созданных отзыва. В ходе теста CRUD создавался и удалялся дополнительный отзыв.

### Стили

- Изучены **Global variables** и **Styles**.
- Создана цветовая переменная `primary-color`; применён пользовательский стиль.
