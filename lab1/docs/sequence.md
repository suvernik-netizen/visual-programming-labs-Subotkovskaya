# Sequence Diagram — Бронирование номера в отеле

```mermaid
sequenceDiagram
    participant K as Клиент
    participant S as Сайт бронирования
    participant M as Менеджер отеля
    participant P as Платёжная система
    participant U as Служба подтверждения

    K->>S: Вводит даты заезда и выезда
    S->>K: Показывает доступные номера
    K->>S: Выбирает номер и нажимает «Забронировать»
    S->>M: Передаёт заявку на проверку
    M->>M: Проверяет доступность номера

    alt Номер доступен
        M->>S: Подтверждает бронь
        S->>P: Передаёт данные для оплаты
        P->>K: Запрашивает данные карты
        K->>P: Вводит платёжные данные
        P->>S: Сообщает результат оплаты

        alt Оплата прошла
            S->>U: Отправляет данные для уведомления
            U-->>K: Отправляет письмо и SMS с деталями
            S->>M: Фиксирует бронь в системе
            S-->>K: Подтверждение бронирования
        else Оплата отклонена
            S-->>K: Предлагает повторить оплату
        end

    else Номер недоступен
        M->>S: Отклоняет заявку
        S-->>K: Предлагает альтернативные номера
    end
