# Процесс: Бронирование номера в отеле

## Название процесса
Бронирование номера в отеле через онлайн-систему.

## Участники (роли)
- Клиент — пользователь, желающий забронировать номер.
- Сайт бронирования — онлайн-система, принимающая заявки.
- Менеджер отеля — сотрудник, подтверждающий бронь.
- Платёжная система — сервис для оплаты.
- Служба подтверждения — отправляет уведомление клиенту.

## Шаги процесса
1. Клиент открывает сайт бронирования и вводит даты заезда и выезда.
2. Сайт отображает список доступных номеров, соответствующих запросу.
3. Клиент выбирает подходящий номер и нажимает «Забронировать».
4. Сайт формирует заявку и отправляет её менеджеру отеля.
5. Менеджер проверяет доступность номера на указанные даты.

### Ветвление 1: проверка доступности
- Если номер доступен, менеджер подтверждает бронь и передаёт заявку в платёжную систему.
- Если номер недоступен, менеджер отклоняет заявку, и сайт предлагает клиенту альтернативные номера.

6. Платёжная система запрашивает у клиента данные карты.
7. Клиент вводит платёжные данные и подтверждает оплату.

### Ветвление 2: проверка оплаты
- Если оплата прошла успешно, система фиксирует бронь.
- Если оплата отклонена, клиенту предлагается повторить платёж или выбрать другой способ оплаты.

### Параллельные действия (после успешной оплаты)
После успешной оплаты одновременно выполняются:
- Служба подтверждения отправляет клиенту письмо и SMS с деталями брони.
- Менеджер отеля вносит данные клиента в журнал заселения.
- Сайт обновляет статус номера на «забронирован» в системе.

8. Клиент получает подтверждение бронирования.
9. Процесс завершается — номер закреплён за клиентом до даты заезда.

## Особенности процесса
- Есть 2 условия ветвления: доступность номера и результат оплаты.
- Есть параллельные действия: уведомление клиента, внесение в журнал, обновление статуса.
- Участников — 5 ролей, что позволяет построить содержательную Sequence-диаграмму.
