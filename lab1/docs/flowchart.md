# Flowchart — Проверка и подтверждение брони

```mermaid
flowchart TD
    A([Начало]) --> B[/Клиент вводит даты/]
    B --> C[Сайт ищет доступные номера]
    C --> D{Есть подходящие номера?}

    D -- Нет --> E[Сообщить клиенту об отсутствии]
    E --> Z([Конец])

    D -- Да --> F[Клиент выбирает номер]
    F --> G[Менеджер проверяет бронь]
    G --> H{Номер доступен?}

    H -- Нет --> I[Предложить альтернативы]
    I --> C

    H -- Да --> J[Клиент оплачивает бронь]
    J --> K{Оплата прошла?}

    K -- Нет --> L[Предложить повторить оплату]
    L --> J

    K -- Да --> M[Система фиксирует бронь]
    M --> N[Отправить уведомление клиенту]
    N --> Z([Конец])
