
# visual-programming-labs-Subotkovskaya

Лабораторные работы по дисциплине «Технологии визуального программирования».

## Структура

- **`lab1/`** — Лабораторная работа №1: моделирование процессов с использованием Git и визуальных нотаций
  - `docs/` — текстовые описания и Mermaid-диаграммы
  - `diagrams/` — BPMN, UML Activity и экспортированные PNG

- **`lab2/`** — Лабораторная работа №2: Node-RED как low-code инструмент
  - `docs/` — отчёт (`report.md`) и документация API (`api.md`)
  - `flows/` — 12 JSON-файлов с потоками Node-RED
  - `screenshots/` — скриншоты всех потоков

- **`lab3/`** — Лабораторная работа №3: no-code приложение «Список книг» на Bubble
  - `docs/` — отчёт (`report.md`)
  - `screenshots/` — скриншоты всех шагов

- **`lab4/`** — Лабораторная работа №4: n8n как low-code платформа автоматизации
  - `docs/` — отчёт (`report.md`) и документация по Redis (`redis.md`)
  - `flows/` — 8 JSON-файлов с workflow n8n
  - `screenshots/` — скриншоты всех workflow

- **`lab5/`** — Лабораторная работа №5: разработка чат-бота на платформе TypeBot
  - `docs/` — отчёт (`report.md`)
  - `exports/` — экспорт сценария чат-бота в формате JSON
  - `screenshots/` — скриншоты сценария, настроек и работы бота

- **`lab6/`** — Лабораторная работа №6: создание мобильного приложения «Приветствие» на Kodular
  - `docs/` — отчёт (`report.md`)
  - `exports/` — исходный проект приложения (`Lab6_Subotkovskaya.aia`)
  - `screenshots/` — скриншоты интерфейса, блоков и ачивки №15 «Генератор случайных пожеланий»

- **`lab7/`** — Лабораторная работа №7: создание системы управления студенческими мероприятиями в Notion
  - `docs/` — отчёт (`report.md`) с описанием модели данных и настроек
  - `exports/` — папка для экспорта проекта (страница опубликована по ссылке)
  - `screenshots/` — скриншоты трёх баз данных, связей Relation, формулы, календаря и кнопки
  - [Открыть проект в Notion](https://holly-socks-39d.notion.site/Lab7_Subotkovskaya-411ae28c8a7b800da272c7f344b55305)

## Используемые технологии

- **Git / GitHub** — контроль версий.
- **BPMN, UML, Mermaid** — визуальные нотации.
- **Node-RED** — low-code для IoT и интеграций.
- **Bubble** — no-code для веб-приложений.
- **n8n** — low-code для автоматизации.
- **Docker** — контейнеризация (Node-RED, n8n, Redis).
- **Redis** — внешнее key-value хранилище.
- **TypeBot** — no-code платформа для создания чат-ботов.
- **Kodular** — low-code/no-code платформа для разработки мобильных Android-приложений.
- **Notion** — no-code платформа для создания связанных баз данных, управления задачами и организации проектов.
