# visual-programming-labs-Subotkovskaya

Лабораторные работы по дисциплине «Технологии визуального программирования».

## Структура

- **`lab1/`** — Лабораторная работа №1: моделирование процессов с использованием Git и визуальных нотаций
  - `docs/` — текстовые описания и Mermaid-диаграммы
  - `diagrams/` — BPMN, UML Activity и экспортированные PNG

- **`lab2/`** — Лабораторная работа №2: Node-RED как low-code инструмент
  - `docs/` — отчёт (`report.md`) и документация API (`api.md`)
  - `flows/` — 12 JSON-файлов с потоками Node-RED
  - `screenshots/` — скриншоты всех потоков

- **`lab3/`** — Лабораторная работа №3: no-code приложение «Список книг» на Bubble
  - `docs/` — отчёт (`report.md`)
  - `screenshots/` — скриншоты всех шагов

- **`lab4/`** — Лабораторная работа №4: n8n как low-code платформа автоматизации
  - `docs/` — отчёт (`report.md`) и документация по Redis (`redis.md`)
  - `flows/` — 8 JSON-файлов с workflow n8n
  - `screenshots/` — скриншоты всех workflow

## Используемые технологии

- **Git / GitHub** — контроль версий.
- **BPMN, UML, Mermaid** — визуальные нотации.
- **Node-RED** — low-code для IoT и интеграций.
- **Bubble** — no-code для веб-приложений.
- **n8n** — low-code для автоматизации.
- **Docker** — контейнеризация (Node-RED, n8n, Redis).
- **Redis** — внешнее key-value хранилище.
